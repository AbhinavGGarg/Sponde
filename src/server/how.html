LAYER 01 · THE LAW

Human consent

commit_deal is the only actionable tool, and each side's call pauses for its own human. An agreement needs two yeses — then the receipt and the real calendar invite are issued, exactly once.

without it — your agent can commit you to anything.
LAYER 02 · THE HARNESS

TrueForge

Runs both agent loops, connects the MCP tools, freezes the destructive call for a human, and keeps a session alive through a refresh mid-negotiation. We wrote zero approval code — the harness enforces consent.

without it — we'd have spent today writing a runtime, not a product.
LAYER 03 · THE MINDS

OpenAI

Each side is a model bargaining for its own human within private constraints — unscripted: every counter you watch was decided, not staged. A full day of live negotiation cost under a dollar.

without a capable model — theater, not negotiation.
LAYER 04 · WHAT WE BUILT

The room

A single MCP server that is the meeting place. Its tools accept only validated offer fields — unknown fields rejected, raw constraints have no channel. Matching dual commits seal a SHA-256 transcript.

without it — the agents have nowhere to meet, and secrets have a channel.
LAYER 05 · THE WORLD

Bright Data

Agents negotiate over fresh venue data pulled live from the web through Bright Data's MCP, inside the same agent loop. Offers carry source_url + retrieved_at — and wear an honest amber flag when a fact wasn't verified live.

without it — two agents haggling over stale guesses.
THE BUILD RAIL

Qodo

Not a runtime layer, and not pretended to be one. Every substantive PR was Qodo-reviewed before merge — 9 real findings in green code, including the one that would have broken dual approval. Each fixed with a named test or answered on the record.

without it — a core promise shipped broken. It caught that before lunch.
ALL LAYERS · ONE MOMENT

Sealed.

Two keys turn, the layers close, and something real happens exactly once: a SHA-256 receipt both sides keep, and a calendar invite that lands on both humans' real calendars. That's the whole product — a room where agents deal and humans decide.
