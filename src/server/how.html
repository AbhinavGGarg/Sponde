TRUEFORGE · the harness Runs both agent loops, connects the MCP tools, freezes the destructive call for approval, and keeps the session alive through a refresh mid-negotiation. without it — we'd have spent today writing a runtime, not a product.
OPENAI · the minds in this run Each side is a model bargaining for its own human within private constraints — unscripted: the counters you watched were decided, not staged. (The harness makes the provider swappable; this run used OpenAI.) without a capable model — theater, not negotiation.
THE ROOM · what we built A single MCP server that is the meeting place. Its tools accept only validated offer fields — unknown fields rejected, raw constraints have no channel. Matching dual commits seal a SHA-256 transcript. without it — the agents have nowhere to meet, and secrets have a channel.
